# 小红书荧光笔高亮型 (XHS Highlight Marker) - 设计规范

> 仿小红书热帖"很少有人讲透的香港储蓄险底层逻辑"风格。
> 米色/牛皮纸背景 + 手写体大字 + 黄色荧光笔高亮，个人IP辨识度强。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | xhs_highlight_marker（荧光笔高亮型）        |
| **适用场景**   | 观点输出、底层逻辑、深度解读、个人IP内容     |
| **设计调性**   | 手写感 + 荧光笔 + 牛皮纸质感，真诚有力     |
| **灵感来源**   | 小红书热帖"很少有人讲透的底层逻辑"（86赞）  |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 小红书 3:4                    |
| **尺寸**       | 1242 × 1660 px                |
| **viewBox**    | `0 0 1242 1660`               |

---

## 三、配色方案

| 角色           | 色值        | 用途                   |
| -------------- | ----------- | ---------------------- |
| **米色背景**   | `#FDF6EC`   | 牛皮纸底色             |
| **荧光黄**     | `#FFEB3B`   | 关键词高亮背景         |
| **荧光黄淡**   | `#FFEB3B` 30% | 要点行底色          |
| **红色强调**   | `#E53935`   | 感叹号、侧边条         |
| **深色文字**   | `#1A1A1A`   | 大标题                 |
| **正文**       | `#333333`   | 要点标题               |
| **说明文字**   | `#555555`   | 要点说明               |

---

## 四、字体选择

标题使用楷体/衬线体模拟手写风格：
`'STKaiti', 'KaiTi', 'Noto Serif CJK SC', serif`

正文使用标准无衬线：
`Arial, 'Helvetica Neue', 'Microsoft YaHei', sans-serif`

---

## 五、页面结构

1. **大标题区** (y: 180-700)：手写体大字 + 荧光笔高亮关键词 + 感叹号
2. **分割线** (y: 740)
3. **要点列表** (y: 830-1370)：4个要点，每个含标题 + 荧光笔底色说明行
4. **底部建议框** (y: 1390-1530)：红色侧边条 + 行动建议
5. **底部** (y: 1570-1660)：作者 + 日期

---

## 六、占位符

| 占位符                    | 用途             |
| ------------------------- | ---------------- |
| `{{TITLE_LINE1/2/3}}`     | 大标题三行       |
| `{{HIGHLIGHT_WORD}}`      | 荧光笔高亮关键词 |
| `{{POINT_1~4_TITLE}}`     | 要点标题         |
| `{{POINT_1~4_DESC}}`      | 要点说明         |
| `{{CTA_TITLE}}`           | 建议框标题       |
| `{{CTA_DESC}}`            | 建议框说明       |
