# 公众号暖色头图 (WeChat Warm) - 设计规范

> 适用于微信公众号生活类、教育类文章头图。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | wechat_warm（公众号暖色头图）              |
| **适用场景**   | 生活类、教育类、情感类文章                 |
| **设计调性**   | Nature Distilled，暖色调                   |
| **主题模式**   | 暖色主题                                   |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 公众号头图 2.35:1             |
| **尺寸**       | 900 × 383 px                  |
| **viewBox**    | `0 0 900 383`                 |
| **页面边距**   | 上 40px，右 50px，下 40px，左 50px |

---

## 三、配色方案

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **赤陶主色**   | `#C67B5C`   | 装饰元素               |
| **米色辅色**   | `#D4C4A8`   | 辅助装饰               |
| **橄榄绿强调** | `#6B7B3C`   | 标签                   |
| **暖白背景**   | `#F5F0E1`   | 整体背景               |
| **深棕文字**   | `#3D3028`   | 主文字                 |

---

## 四、SVG 技术约束

遵循 PPT Master 全局 SVG 约束。

---

## 五、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 文章标题         |
| `{{SUBTITLE}}` | 副标题         |
| `{{AUTHOR}}` | 公众号名称       |
