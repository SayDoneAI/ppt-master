# 小红书产品种草 (XHS Product) - 设计规范

> 适用于小红书平台的产品种草、生活方式、美妆推荐类图文内容。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | xhs_product（小红书产品种草）              |
| **适用场景**   | 产品种草、生活方式、美妆、好物推荐         |
| **设计调性**   | Nature Distilled，暖色调、有机质感         |
| **主题模式**   | 暖色浅色主题                               |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 小红书 3:4                    |
| **尺寸**       | 1242 × 1660 px                |
| **viewBox**    | `0 0 1242 1660`               |
| **页面边距**   | 上 80px，右 60px，下 80px，左 60px |
| **内容安全区** | x: 60-1182, y: 80-1580       |

---

## 三、配色方案

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **赤陶主色**   | `#C67B5C`   | 标题强调、装饰         |
| **米色辅色**   | `#D4C4A8`   | 卡片背景、分割线       |
| **橄榄绿强调** | `#6B7B3C`   | 标签、价格、CTA        |
| **暖白背景**   | `#F5F0E1`   | 整体背景               |
| **深棕文字**   | `#3D3028`   | 主文字                 |
| **中棕辅助**   | `#8B7355`   | 说明文字               |

---

## 四、排版体系

| 层级         | 字号   | 字重    | 用途           |
| ------------ | ------ | ------- | -------------- |
| **主标题**   | 52px   | Bold    | 产品名称/大标题 |
| **副标题**   | 28px   | Regular | 描述文字       |
| **正文**     | 24px   | Regular | 详情内容       |
| **标注**     | 20px   | Regular | 标签、来源     |

字体栈：`Arial, "Helvetica Neue", "Microsoft YaHei", sans-serif`

---

## 五、页面结构

1. **标题区** (y: 80-200)：主标题 + 副标题
2. **主图区** (y: 220-740)：大图展示
3. **特点区** (y: 780-1300)：产品特点卡片
4. **底部区** (y: 1480-1580)：作者 + CTA

---

## 六、SVG 技术约束

遵循 PPT Master 全局 SVG 约束。

---

## 七、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 产品/主题名称    |
| `{{SUBTITLE}}` | 副标题/一句话描述 |
| `{{BODY}}`   | 详细内容         |
| `{{IMAGE}}`  | 产品图片区       |
| `{{AUTHOR}}` | 作者/品牌        |
| `{{CTA}}`    | 行动号召         |
