# 小红书数字冲击型 (XHS Number Impact) - 设计规范

> 仿小红书热帖"飞到香港存了200万 利息5.01%"风格。
> 深色背景 + 超大数字 + 金色强调，适合金融数据、收益展示、数字冲击类内容。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | xhs_number_impact（数字冲击型）             |
| **适用场景**   | 收益展示、数据对比、关键指标、理财案例       |
| **设计调性**   | 深色 + 金色强调 + 超大数字，信任感+财富感   |
| **灵感来源**   | 小红书热帖"存了200万 利息5.01%"（173赞）    |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 小红书 3:4                    |
| **尺寸**       | 1242 × 1660 px                |
| **viewBox**    | `0 0 1242 1660`               |

---

## 三、配色方案

| 角色           | 色值        | 用途                   |
| -------------- | ----------- | ---------------------- |
| **深色背景**   | `#0D1117`   | 页面背景               |
| **卡片背景**   | `#161B22`   | 数据卡片               |
| **金色强调**   | `#F5A623`   | 核心数字、标签、CTA    |
| **蓝色辅助**   | `#58A6FF`   | 次要数字               |
| **绿色**       | `#3FB950`   | 正向指标               |
| **白色文字**   | `#FFFFFF`   | 标题                   |
| **灰色文字**   | `#8B949E`   | 说明标签               |
| **浅灰文字**   | `#C9D1D9`   | 正文                   |

---

## 四、页面结构

1. **标签+标题** (y: 60-240)：金色胶囊标签 + 白色大标题
2. **核心大数字** (y: 300-660)：160px超大金色数字 + 说明
3. **三列数据卡** (y: 710-910)：三个对比指标
4. **详情列表** (y: 960-1440)：5条要点说明
5. **CTA + 底部** (y: 1490-1660)：行动号召按钮

---

## 五、占位符

| 占位符                        | 用途             |
| ----------------------------- | ---------------- |
| `{{TAG}}`                     | 顶部标签         |
| `{{TITLE}}`                   | 大标题           |
| `{{BIG_NUMBER}}`              | 核心大数字       |
| `{{BIG_NUMBER_LABEL/NOTE}}`   | 数字标签/注释    |
| `{{STAT_1~3_VALUE/LABEL}}`    | 三列数据         |
| `{{DETAIL_TITLE}}`            | 详情标题         |
| `{{DETAIL_1~5}}`              | 详情条目         |
| `{{CTA}}`                     | 行动号召         |
