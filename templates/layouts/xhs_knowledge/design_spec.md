# 小红书知识卡片 (XHS Knowledge) - 设计规范

> 适用于小红书平台的知识分享、干货拆解、教程类图文内容。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | xhs_knowledge（小红书知识卡片）            |
| **适用场景**   | 知识分享、干货拆解、教程、学习笔记         |
| **设计调性**   | Bento Grid + Flat Design，卡片堆叠、清晰   |
| **主题模式**   | 浅色主题                                   |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 小红书 3:4                    |
| **尺寸**       | 1242 × 1660 px                |
| **viewBox**    | `0 0 1242 1660`               |
| **页面边距**   | 上 80px，右 60px，下 80px，左 60px |
| **内容安全区** | x: 60-1182, y: 80-1580       |

---

## 三、配色方案

### 主色系

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **石板灰主色** | `#475569`   | 卡片标题、图标         |
| **石板灰辅色** | `#64748B`   | 次要文字               |
| **蓝色强调**   | `#2563EB`   | 编号、高亮、按钮       |
| **浅蓝背景**   | `#DBEAFE`   | 强调卡片背景           |
| **页面背景**   | `#F8FAFC`   | 整体背景               |

### 文字色系

| 角色           | 色值        | 用途                   |
| -------------- | ----------- | ---------------------- |
| **主文字**     | `#1E293B`   | 标题、正文             |
| **辅助文字**   | `#64748B`   | 说明文字               |
| **白色文字**   | `#FFFFFF`   | 蓝色背景上的文字       |

---

## 四、排版体系

| 层级         | 字号   | 字重    | 用途           |
| ------------ | ------ | ------- | -------------- |
| **主标题**   | 56px   | Bold    | 页面大标题     |
| **副标题**   | 32px   | Regular | 说明文字       |
| **卡片标题** | 28px   | Bold    | 知识点标题     |
| **正文**     | 24px   | Regular | 卡片内容       |
| **标注**     | 20px   | Regular | 来源、标签     |

字体栈：`Arial, "Helvetica Neue", "Microsoft YaHei", sans-serif`

---

## 五、页面结构

海报为单页结构，自上而下分为：

1. **标题区** (y: 80-260)：主标题 + 副标题
2. **内容区** (y: 280-1460)：Bento Grid 卡片区域
3. **底部区** (y: 1480-1580)：作者/品牌 + 标签

---

## 六、布局模式

### Bento Grid 布局

- 卡片圆角：16px
- 卡片间距：20px
- 卡片内边距：24px
- 支持全宽、半宽、三分之一宽卡片混排

---

## 七、间距规范

| 元素         | 间距   |
| ------------ | ------ |
| 标题与内容区 | 20px   |
| 卡片间距     | 20px   |
| 卡片内边距   | 24px   |
| 底部与内容区 | 20px   |

---

## 八、SVG 技术约束

遵循 PPT Master 全局 SVG 约束：
- 禁止：`clipPath`、`mask`、`<style>`、`class/id`、`<foreignObject>`、`textPath`、`animate*`、`script`、`marker-end`、`rgba()`、`<g opacity>`
- 使用：内联样式、`fill-opacity`、`<tspan>` 换行、`<rect>` 背景

---

## 九、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 主标题           |
| `{{SUBTITLE}}` | 副标题/描述    |
| `{{BODY}}`   | 正文内容区       |
| `{{AUTHOR}}` | 作者/品牌名      |
| `{{IMAGE}}`  | 图片占位区       |

---

## 十、使用说明

1. 复制模板到项目 `templates/` 目录
2. 阅读本设计规范了解配色和排版参数
3. 根据内容类型选择 `01_main.svg`（标准）或 `02_variant_a.svg`（图文混排）
4. 使用 Executor 角色根据模板生成最终 SVG
