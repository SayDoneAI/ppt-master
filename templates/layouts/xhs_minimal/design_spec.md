# 小红书极简金句 (XHS Minimal) - 设计规范

> 适用于小红书平台的金句卡片、个人IP内容、观点输出类图文。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | xhs_minimal（小红书极简金句）              |
| **适用场景**   | 金句卡片、个人IP、观点输出、情感语录       |
| **设计调性**   | Exaggerated Minimalism，大字极简、黑白+单色 |
| **主题模式**   | 白色极简主题                               |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 小红书 3:4                    |
| **尺寸**       | 1242 × 1660 px                |
| **viewBox**    | `0 0 1242 1660`               |
| **页面边距**   | 上 120px，右 80px，下 120px，左 80px |
| **内容安全区** | x: 80-1162, y: 120-1540      |

---

## 三、配色方案

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **纯黑主色**   | `#000000`   | 主标题文字             |
| **纯白背景**   | `#FFFFFF`   | 页面背景               |
| **浅灰辅助**   | `#F5F5F5`   | 装饰块                 |
| **中灰文字**   | `#999999`   | 辅助文字               |

---

## 四、排版体系

| 层级         | 字号   | 字重    | 用途           |
| ------------ | ------ | ------- | -------------- |
| **超大标题** | 80px   | Black   | 核心金句       |
| **副标题**   | 28px   | Regular | 补充说明       |
| **署名**     | 24px   | Regular | 作者名称       |
| **标注**     | 18px   | Regular | 日期、标签     |

字体栈：`Arial, "Helvetica Neue", "Microsoft YaHei", sans-serif`

---

## 五、SVG 技术约束

遵循 PPT Master 全局 SVG 约束。

---

## 六、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 核心金句         |
| `{{SUBTITLE}}` | 补充说明       |
| `{{AUTHOR}}` | 署名             |
| `{{DATE}}`   | 日期             |
