# Story 优雅海报 (Story Elegant) - 设计规范

> 适用于生活方式分享、品牌故事、优雅调性的竖屏 Story。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | story_elegant（Story 优雅海报）            |
| **适用场景**   | 生活方式、品牌故事、优雅展示               |
| **设计调性**   | Nature Distilled，暖色、优雅               |
| **主题模式**   | 暖色主题                                   |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | Story 9:16                    |
| **尺寸**       | 1080 × 1920 px                |
| **viewBox**    | `0 0 1080 1920`               |
| **页面边距**   | 上 120px，右 80px，下 180px，左 80px |

---

## 三、配色方案

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **赤陶主色**   | `#C67B5C`   | 标题装饰               |
| **米色辅色**   | `#D4C4A8`   | 卡片背景               |
| **橄榄绿强调** | `#6B7B3C`   | 标签、CTA              |
| **暖白背景**   | `#F5F0E1`   | 整体背景               |
| **深棕文字**   | `#3D3028`   | 主文字                 |

---

## 四、SVG 技术约束

遵循 PPT Master 全局 SVG 约束。

---

## 五、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 主标题           |
| `{{SUBTITLE}}` | 副标题         |
| `{{BODY}}`   | 正文             |
| `{{IMAGE}}`  | 图片区           |
| `{{AUTHOR}}` | 品牌/作者        |
| `{{CTA}}`    | 行动号召         |
