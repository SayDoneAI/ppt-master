# 朋友圈品牌海报 (Moments Brand) - 设计规范

> 适用于微信朋友圈的品牌展示、公司宣传、高端营销场景。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | moments_brand（朋友圈品牌海报）            |
| **适用场景**   | 品牌展示、公司宣传、高端产品               |
| **设计调性**   | Glassmorphism，毛玻璃、高端质感            |
| **主题模式**   | 深色渐变主题                               |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 朋友圈 1:1                    |
| **尺寸**       | 1080 × 1080 px                |
| **viewBox**    | `0 0 1080 1080`               |
| **页面边距**   | 全方向 80px                   |

---

## 三、配色方案

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **靛蓝主色**   | `#6366F1`   | 渐变起始               |
| **紫色辅色**   | `#8B5CF6`   | 渐变终点               |
| **粉色强调**   | `#EC4899`   | 装饰光效               |
| **白色文字**   | `#FFFFFF`   | 主要文字               |
| **半透白**     | `#FFFFFF`   | 毛玻璃卡片 (opacity)   |

---

## 四、SVG 技术约束

遵循 PPT Master 全局 SVG 约束。
注意：用 `fill-opacity` 模拟毛玻璃效果，禁止使用 `filter`/`backdrop-filter`。

---

## 五、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 品牌/产品名称    |
| `{{SUBTITLE}}` | 品牌口号       |
| `{{BODY}}`   | 详细描述         |
| `{{AUTHOR}}` | 公司名           |
| `{{IMAGE}}`  | 产品/品牌图      |
| `{{QR_CODE}}` | 二维码区        |
