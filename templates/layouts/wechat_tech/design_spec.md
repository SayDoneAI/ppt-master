# 公众号科技头图 (WeChat Tech) - 设计规范

> 适用于微信公众号技术文章、行业分析类文章头图。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | wechat_tech（公众号科技头图）              |
| **适用场景**   | 技术文章、行业分析、数据报告               |
| **设计调性**   | Flat Design，科技蓝、简洁                  |
| **主题模式**   | 浅色主题                                   |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 公众号头图 2.35:1             |
| **尺寸**       | 900 × 383 px                  |
| **viewBox**    | `0 0 900 383`                 |
| **页面边距**   | 上 40px，右 50px，下 40px，左 50px |

---

## 三、配色方案

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **科技蓝主色** | `#0078D7`   | 主色调                 |
| **天蓝辅色**   | `#00A4EF`   | 辅助色                 |
| **橙红强调**   | `#F25022`   | 强调元素               |
| **浅灰背景**   | `#F5F5F7`   | 整体背景               |
| **深灰文字**   | `#333333`   | 正文                   |

---

## 四、SVG 技术约束

遵循 PPT Master 全局 SVG 约束。

---

## 五、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 文章标题         |
| `{{SUBTITLE}}` | 副标题         |
| `{{AUTHOR}}` | 公众号名称       |
| `{{IMAGE}}`  | 配图区           |
