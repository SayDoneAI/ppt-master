# 小红书金字塔排名 (XHS Pyramid Rank) - 设计规范

> 仿小红书热帖"2025香港八大保险品牌实力测评"风格。
> 彩色金字塔层级图 + 两侧标注，适合品牌排名、等级评测、层级展示。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | xhs_pyramid_rank（金字塔排名图）            |
| **适用场景**   | 品牌排名、等级评测、层级对比、实力测评       |
| **设计调性**   | 彩色渐变金字塔 + 两侧数据标注              |
| **灵感来源**   | 小红书热帖"八大保险品牌实力测评"（116赞）   |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 小红书 3:4                    |
| **尺寸**       | 1242 × 1660 px                |
| **viewBox**    | `0 0 1242 1660`               |

---

## 三、配色方案（金字塔从上到下）

| 层级  | 色值        | 含义                   |
| ----- | ----------- | ---------------------- |
| 第1层 | `#E53935`   | 顶级/最高              |
| 第2层 | `#FF5722`   | 优秀                   |
| 第3层 | `#FF9800`   | 良好                   |
| 第4层 | `#FFC107`   | 中等偏上               |
| 第5层 | `#8BC34A`   | 中等                   |
| 第6层 | `#4CAF50`   | 入门                   |

---

## 四、页面结构

1. **标题区** (y: 60-260)：大标题 + 装饰线
2. **列标签** (y: 300-370)：左右列标题
3. **金字塔** (y: 400-1170)：6层彩色金字塔 + 两侧标注
4. **说明区** (y: 1240-1520)：白色卡片，补充说明
5. **底部** (y: 1560-1660)：作者 + 日期

---

## 五、占位符

| 占位符                        | 用途             |
| ----------------------------- | ---------------- |
| `{{TITLE_LINE1/2}}`           | 大标题           |
| `{{LABEL_COL_LEFT/RIGHT}}`    | 列标题           |
| `{{RANK_1~6}}`                | 金字塔层名       |
| `{{RANK_1~6_LEFT}}`           | 左侧标注         |
| `{{RANK_1~6_RIGHT}}`          | 右侧标注（评级） |
| `{{NOTE_TITLE}}`              | 说明标题         |
| `{{NOTE_1~3}}`                | 说明条目         |
| `{{DISCLAIMER}}`              | 免责声明         |
