# Story 活力海报 (Story Vibrant) - 设计规范

> 适用于 Instagram Story、抖音封面、短视频封面等竖屏快拍场景。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | story_vibrant（Story 活力海报）            |
| **适用场景**   | 短视频封面、活动快拍、限时动态             |
| **设计调性**   | Vibrant Block，大色块、醒目标题            |
| **主题模式**   | 彩色主题                                   |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | Story 9:16                    |
| **尺寸**       | 1080 × 1920 px                |
| **viewBox**    | `0 0 1080 1920`               |
| **页面边距**   | 上 120px，右 60px，下 180px，左 60px |
| **内容安全区** | x: 60-1020, y: 120-1740      |

---

## 三、配色方案

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **蓝色主色**   | `#2563EB`   | 主色块                 |
| **紫色辅色**   | `#7C3AED`   | 辅色块                 |
| **橙色强调**   | `#F97316`   | CTA 按钮               |
| **浅底背景**   | `#F8FAFC`   | 整体背景               |
| **深色文字**   | `#1E293B`   | 正文                   |

---

## 四、SVG 技术约束

遵循 PPT Master 全局 SVG 约束。

---

## 五、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 大标题           |
| `{{SUBTITLE}}` | 副标题         |
| `{{BODY}}`   | 正文内容         |
| `{{IMAGE}}`  | 图片区           |
| `{{CTA}}`    | 行动号召         |
| `{{AUTHOR}}` | 品牌/作者        |
