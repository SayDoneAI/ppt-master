# 小红书清单型 (XHS Checklist) - 设计规范

> 仿小红书热门帖"买港险不想被坑，建议背烂这张图"风格。
> 白底 + 彩色标签分区 + 编号列表，适合"N个要点/N个避坑"类干货图文。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | xhs_checklist（清单型信息图）               |
| **适用场景**   | 避坑指南、购买攻略、要点清单、Do/Don't 对比 |
| **设计调性**   | 白底 + 红绿蓝三色分区，实用工具感          |
| **灵感来源**   | 小红书热帖（845赞+1252收藏）               |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 小红书 3:4                    |
| **尺寸**       | 1242 × 1660 px                |
| **viewBox**    | `0 0 1242 1660`               |
| **页面边距**   | 上 60px，右 60px，下 80px，左 60px |

---

## 三、配色方案

| 角色           | 色值        | 用途                   |
| -------------- | ----------- | ---------------------- |
| **红色**       | `#E53935`   | "不要"类标签、关键词高亮 |
| **绿色**       | `#43A047`   | "要"类标签             |
| **蓝色**       | `#1565C0`   | "适合人群"类标签       |
| **主文字**     | `#333333`   | 正文                   |
| **辅助文字**   | `#666666`   | 副标题                 |
| **背景**       | `#FFFFFF`   | 白色                   |

---

## 四、排版体系

| 层级         | 字号   | 字重    | 用途           |
| ------------ | ------ | ------- | -------------- |
| **大标题**   | 64px   | Bold    | 封面标题       |
| **副标题**   | 28px   | Regular | 说明文字       |
| **区块标签** | 24px   | Bold    | 分区标题       |
| **条目正文** | 28px   | Regular | 列表内容       |
| **底部信息** | 22px   | Regular | 作者/标签      |

---

## 五、页面结构

1. **标题区** (y: 60-370)：红色标签 + 大字标题 + 关键词高亮
2. **区块A** (y: 410-790)：红色标签 + 6条避坑/不要项
3. **区块B** (y: 820-1150)：绿色标签 + 5条推荐/要做项
4. **区块C** (y: 1180-1400)：蓝色标签 + 3条适用人群/条件
5. **底部区** (y: 1540-1660)：作者 + 引导收藏

---

## 六、占位符

| 占位符              | 用途                 |
| ------------------- | -------------------- |
| `{{TAG}}`           | 顶部标签（如"保险知识"）|
| `{{TITLE_LINE1/2}}` | 大标题两行           |
| `{{KEYWORD}}`       | 高亮关键词           |
| `{{SECTION_A/B/C}}` | 分区标签文字         |
| `{{A_ITEM_1~6}}`   | 区块A条目            |
| `{{B_ITEM_1~5}}`   | 区块B条目            |
| `{{C_ITEM_1~3}}`   | 区块C条目            |
| `{{AUTHOR}}`        | 作者名               |
