# 企业 Banner (Banner Corporate) - 设计规范

> 适用于企业官网、产品发布、商务营销的横幅海报。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | banner_corporate（企业 Banner）            |
| **适用场景**   | 企业官网、产品发布、商务营销               |
| **设计调性**   | Trust & Authority，专业蓝灰、信任感        |
| **主题模式**   | 深色主题                                   |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | Banner 16:9                   |
| **尺寸**       | 1920 × 1080 px                |
| **viewBox**    | `0 0 1920 1080`               |
| **页面边距**   | 上 100px，右 120px，下 100px，左 120px |

---

## 三、配色方案

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **深蓝主色**   | `#1E40AF`   | 主背景、标题           |
| **石板灰辅色** | `#475569`   | 辅助文字               |
| **琥珀强调**   | `#F59E0B`   | CTA、强调元素          |
| **浅底背景**   | `#F8FAFC`   | 亮色区域               |
| **深色文字**   | `#1E293B`   | 正文                   |

---

## 四、SVG 技术约束

遵循 PPT Master 全局 SVG 约束。

---

## 五、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 主标题           |
| `{{SUBTITLE}}` | 副标题         |
| `{{BODY}}`   | 正文/卖点        |
| `{{IMAGE}}`  | 主视觉图         |
| `{{CTA}}`    | 行动号召         |
| `{{AUTHOR}}` | 品牌/Logo 名称   |
