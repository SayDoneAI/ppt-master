# 创意 Banner (Banner Creative) - 设计规范

> 适用于创意展示、活动横幅、视觉冲击力强的营销场景。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | banner_creative（创意 Banner）             |
| **适用场景**   | 创意展示、活动横幅、品牌营销               |
| **设计调性**   | Aurora UI，渐变流动、视觉冲击              |
| **主题模式**   | 深色渐变主题                               |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | Banner 16:9                   |
| **尺寸**       | 1920 × 1080 px                |
| **viewBox**    | `0 0 1920 1080`               |
| **页面边距**   | 上 100px，右 120px，下 100px，左 120px |

---

## 三、配色方案

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **蓝色主色**   | `#0080FF`   | 渐变起始               |
| **品红辅色**   | `#FF1493`   | 渐变辅助               |
| **青色强调**   | `#00FFFF`   | 装饰光效               |
| **白色文字**   | `#FFFFFF`   | 主要文字               |

---

## 四、SVG 技术约束

遵循 PPT Master 全局 SVG 约束。

---

## 五、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 大标题           |
| `{{SUBTITLE}}` | 副标题         |
| `{{BODY}}`   | 正文             |
| `{{CTA}}`    | 行动号召         |
| `{{AUTHOR}}` | 品牌名称         |
