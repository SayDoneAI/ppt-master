# 小红书图文叠加型 (XHS Photo Overlay) - 设计规范

> 仿小红书热帖"飞到香港存了200万"和"保诚高管回应"风格。
> 上部实拍照片 + 文字叠加 + 下部白色要点区域，适合场景化内容+数据展示。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | xhs_photo_overlay（图文叠加型）             |
| **适用场景**   | 实地体验、新闻资讯、案例分享、场景化展示     |
| **设计调性**   | 实拍真实感 + 大字冲击 + 数据高亮            |
| **灵感来源**   | 小红书热帖"存了200万"、"保诚高管"           |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 小红书 3:4                    |
| **尺寸**       | 1242 × 1660 px                |
| **viewBox**    | `0 0 1242 1660`               |

---

## 三、配色方案

| 角色           | 色值        | 用途                   |
| -------------- | ----------- | ---------------------- |
| **图片占位**   | `#E8E8E8`   | 待替换照片区域         |
| **半透明黑底** | `#000000` 55% | 图上文字底             |
| **红色强调**   | `#E53935`   | 高亮条、圆点、装饰条   |
| **白色**       | `#FFFFFF`   | 叠加文字、内容区背景   |
| **主文字**     | `#333333`   | 正文                   |
| **橙色提示**   | `#E65100`   | 提示框标题             |
| **提示背景**   | `#FFF3E0`   | 提示框底色             |

---

## 四、页面结构

1. **图片区** (y: 0-760)：全宽照片 + 半透明黑底文字叠加
2. **数字高亮条** (y: 760-880)：红色底 + 白色大字数据
3. **要点列表** (y: 880-1340)：标题 + 5条圆点列表
4. **提示框** (y: 1360-1480)：橙色提示/建议
5. **底部** (y: 1540-1660)：作者 + 日期 + 红色装饰条

---

## 五、占位符

| 占位符                    | 用途             |
| ------------------------- | ---------------- |
| `{{IMAGE}}`               | 图片占位         |
| `{{OVERLAY_LINE1/2}}`     | 图上叠加文字     |
| `{{HIGHLIGHT_STAT}}`      | 红色高亮数据     |
| `{{CONTENT_TITLE}}`       | 内容区标题       |
| `{{POINT_1~5}}`           | 要点列表         |
| `{{TIP_TITLE}}`           | 提示框标题       |
| `{{TIP_DESC}}`            | 提示框说明       |
