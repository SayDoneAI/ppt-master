# 朋友圈活动海报 (Moments Event) - 设计规范

> 适用于微信朋友圈的活动宣传、促销、发布会等场景。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | moments_event（朋友圈活动海报）            |
| **适用场景**   | 活动宣传、促销、发布会、开业               |
| **设计调性**   | Vibrant Block，色块拼接、活力              |
| **主题模式**   | 彩色活力主题                               |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 朋友圈 1:1                    |
| **尺寸**       | 1080 × 1080 px                |
| **viewBox**    | `0 0 1080 1080`               |
| **页面边距**   | 全方向 60px                   |

---

## 三、配色方案

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **蓝色主色**   | `#2563EB`   | 主色块背景             |
| **紫色辅色**   | `#7C3AED`   | 辅色块                 |
| **橙色强调**   | `#F97316`   | CTA、价格、强调        |
| **浅底背景**   | `#F8FAFC`   | 整体背景               |
| **深色文字**   | `#1E293B`   | 正文                   |

---

## 四、SVG 技术约束

遵循 PPT Master 全局 SVG 约束。

---

## 五、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 活动名称         |
| `{{SUBTITLE}}` | 活动描述       |
| `{{BODY}}`   | 详情内容         |
| `{{DATE}}`   | 活动日期         |
| `{{CTA}}`    | 行动号召         |
| `{{QR_CODE}}` | 二维码区        |
