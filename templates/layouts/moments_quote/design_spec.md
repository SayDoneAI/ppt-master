# 朋友圈金句海报 (Moments Quote) - 设计规范

> 适用于微信朋友圈的金句海报、每日一言、名言分享。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | moments_quote（朋友圈金句海报）            |
| **适用场景**   | 金句海报、每日一言、名言分享               |
| **设计调性**   | Exaggerated Minimalism，超大字、高对比     |
| **主题模式**   | 深色主题                                   |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 朋友圈 1:1                    |
| **尺寸**       | 1080 × 1080 px                |
| **viewBox**    | `0 0 1080 1080`               |
| **页面边距**   | 全方向 80px                   |
| **内容安全区** | x: 80-1000, y: 80-1000       |

---

## 三、配色方案

| 角色           | 色值        | 备注                   |
| -------------- | ----------- | ---------------------- |
| **深黑背景**   | `#111111`   | 页面背景               |
| **纯白文字**   | `#FFFFFF`   | 主标题                 |
| **灰色辅助**   | `#666666`   | 分割线、辅助文字       |
| **浅灰署名**   | `#AAAAAA`   | 作者名                 |

---

## 四、排版体系

| 层级         | 字号   | 字重    | 用途           |
| ------------ | ------ | ------- | -------------- |
| **金句**     | 64px   | Bold    | 核心文字       |
| **副标题**   | 24px   | Regular | 说明/翻译      |
| **署名**     | 22px   | Regular | 作者           |

字体栈：`Arial, "Helvetica Neue", "Microsoft YaHei", sans-serif`

---

## 五、SVG 技术约束

遵循 PPT Master 全局 SVG 约束。

---

## 六、占位符规范

| 占位符       | 用途             |
| ------------ | ---------------- |
| `{{TITLE}}`  | 核心金句         |
| `{{SUBTITLE}}` | 补充说明       |
| `{{AUTHOR}}` | 署名             |
| `{{DATE}}`   | 日期             |
