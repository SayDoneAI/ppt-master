# 小红书渐变特性卡片 (XHS Gradient Features) - 设计规范

> 仿小红书热帖"香港储蓄险8大优势"风格。
> 暖色渐变背景 + 编号圆形图标 + 特性列表，适合产品优势/功能介绍。

---

## 一、模板概述

| 属性           | 描述                                       |
| -------------- | ------------------------------------------ |
| **模板名称**   | xhs_gradient_features（渐变特性卡片）       |
| **适用场景**   | 产品优势、N大理由、功能列表、正面宣传       |
| **设计调性**   | 暖色渐变 + 圆形编号 + 卡片式布局            |
| **灵感来源**   | 小红书热帖"储蓄险8大优势"                   |

---

## 二、画布规范

| 属性           | 值                            |
| -------------- | ----------------------------- |
| **格式**       | 小红书 3:4                    |
| **尺寸**       | 1242 × 1660 px                |
| **viewBox**    | `0 0 1242 1660`               |

---

## 三、配色方案

| 角色           | 色值        | 用途                   |
| -------------- | ----------- | ---------------------- |
| **主色橙**     | `#FF9800`   | 编号圆形、装饰线       |
| **深橙标题**   | `#E65100`   | 大标题                 |
| **卡片背景**   | `#FFF8E1`   | 特性行底色             |
| **页面背景**   | `#FFF3E0`   | 暖色底                 |
| **主文字**     | `#333333`   | 特性标题               |
| **辅助文字**   | `#666666`   | 特性说明               |

---

## 四、页面结构

1. **标题区** (y: 100-280)：大字标题 + 装饰线
2. **特性列表** (y: 330-1430)：8行特性卡片，每行含编号圆形 + 标题 + 说明
3. **底部区** (y: 1540-1620)：作者 + 日期

---

## 五、占位符

| 占位符                   | 用途           |
| ------------------------ | -------------- |
| `{{TITLE_LINE1/2}}`      | 大标题两行     |
| `{{FEAT_1~8_TITLE}}`     | 特性标题       |
| `{{FEAT_1~8_DESC}}`      | 特性说明       |
| `{{AUTHOR}}` `{{DATE}}`  | 底部信息       |
