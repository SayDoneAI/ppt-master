>
> 案例来源：[PicoTrex/Awesome-Nano-Banana-images](https://github.com/PicoTrex/Awesome-Nano-Banana-images)（Apache 2.0）
>
> 共 162 个案例，按用途分为 9 个大类。

## 使用方式

1. **AI 生成海报时** — 根据用户需求选择对应分类，参考其中的 Prompt 模板
2. **`nano_banana_gen.py`** — 将参考 Prompt 适配为实际生图指令
3. **布局 × 风格组合** — 从 `templates/layouts/` 选布局，从这里选风格，自由搭配

## Prompt 编写通用模板

基于 162 个案例总结的高质量 Prompt 结构：

```
[主体描述] + [风格/材质] + [光照] + [构图/视角] + [背景] + [色彩] + [渲染品质] + [比例]
```

### 关键要素

| 要素 | 说明 | 示例 |
|------|------|------|
| 主体 | 清晰描述核心对象 | "一杯拿铁咖啡，拉花形状为树叶" |
| 风格 | 指定视觉风格 | "赛博朋克风格"、"浮世绘风格"、"极简扁平设计" |
| 材质 | 物体质感 | "水晶质感"、"毛绒材质"、"亚克力板" |
| 光照 | 光源类型和方向 | "柔和自然光"、"霓虹灯光"、"rim lighting" |
| 构图 | 视角和布局 | "俯视图"、"等距视角"、"居中构图" |
| 背景 | 环境描述 | "纯白背景"、"渐变深蓝"、"模糊城市夜景" |
| 色彩 | 色调倾向 | "暖色调"、"高对比"、"粉紫配色" |
| 品质 | 渲染质量关键词 | "高清"、"4K"、"产品级摄影" |

### 海报场景常用 Prompt 模式

**产品展示图：**
```
[产品名称]的产品照片，[材质/质感]，[光照方式]，[视角]，纯色背景，产品级摄影，高清 4K
```

**氛围背景图：**
```
[风格]风格的[场景]，[色彩方案]配色，[光照]，适合作为[用途]的背景图，无文字
```

**金句卡片配图：**
```
极简设计，[主题相关的象征物]，[色调]色调，大面积留白，适合叠加文字
```

**信息图配图：**
```
[主题]的[图表类型]，扁平设计风格，[配色方案]，清晰的数据标注，信息图风格
```
